# V2 预算与成本阶段 5：实际成本来源——采购单据

## 目标

将已审核采购入库产生的材料成本，自动归集到项目实际成本。采购订单是唯一可录入项目及成本类别的采购单据；到货、入库只继承并只读展示，入库审核后才形成有效成本。

## 范围与业务口径

- 仅支持标准采购链路：`采购订单 → 到货单 → 入库单 → 项目实际成本`。
- 采购订单可不关联项目；未关联项目即普通采购，不产生项目成本。
- 一张采购订单最多关联一个项目和一个项目分类预算成本类别。关联项目时成本类别必填，且必须是该项目已批准、有效的分类预算类别；若存在“材料费”，默认选择它。
- 订单行单价统一按人民币含税单价使用。到货金额 = 到货数量 × 来源订单含税单价；入库金额 = 入库数量 × 来源订单含税单价。
- 项目、成本类别只允许在采购订单维护；到货、入库继承快照，只读。
- 一张入库单的每一条关联项目的入库明细生成一条实际成本。成本归集在入库审核时生效；入库弃审后原成本记录标记为已冲销，不物理删除。
- 项目实际成本仍为统一成本事实表：本阶段新增采购入库来源，保留已有手工登记来源；不新建采购成本业务表。

## 实际成本最小来源字段

| 字段 | 含义 |
| --- | --- |
| `source_type` | `MANUAL` 或 `PURCHASE_INBOUND` |
| `source_line_id` | 采购来源时为入库明细 ID，唯一业务来源 |
| `source_document_no` | 入库单号快照 |
| `cost_status` | `EFFECTIVE` 或 `REVERSED` |
| `reverse_reason` / `reversed_by` / `reversed_time` | 冲销审计 |

不在实际成本重复保存采购订单、到货单、供应商、数量、单价等字段；这些信息从 `source_line_id` 关联的入库明细及其来源链查询。

## 页面与权限

- 采购订单编辑页增加“项目归集”区域：项目（可选）与成本类别（关联项目后必填）。
- 到货单、入库单展示项目、成本类别和金额快照，均不可编辑。
- 项目预算页的实际成本列表展示来源、来源单号、状态；采购来源不可手工编辑或删除，并提供查看入库单入口。
- 项目成员/负责人沿用项目实际成本查看范围；采购单据仍遵循采购模块现有权限。管理员不作为项目业务权限例外。

## 约束与非目标

- 直接到货、直接入库不带项目字段，不产生项目成本。
- 仅“已审核且未冲销”的成本参与预算执行金额、剩余预算和执行率。
- 采购来源成本不允许从项目预算页修改、删除或换成本类别；必须通过入库弃审冲销。
- 本阶段不做采购退货、红字发票、供应商对账、费用报销、工时成本、财务凭证同步。
