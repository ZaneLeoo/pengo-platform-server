# V2 预算与成本 02：项目分类预算产品需求

## 1. 目标

将立项申请中的预算总额细分到成本类别，并随立项审批形成受控预算。项目启动后的预算调整统一通过项目变更流程。

## 2. 业务规则

- 预算采用人民币含税口径，金额保留两位小数。
- 需要预算时，总额必须大于 0，至少包含一条分类明细；每条明细包含有效末级成本类别、金额和测算依据。
- 同一项目不能重复选择成本类别，明细金额必须大于 0。
- 草稿允许明细合计与总额不一致；提交立项或项目变更时必须完全相等。
- 不需要预算时，总额、预算说明和明细必须为空。
- 资源预算附件沿用立项材料 `RESOURCE_BUDGET`，不增加明细附件。
- 新增独立预置末级类别 `CONTINGENCY / 预备费`，不设置比例硬上限。
- 已引用类别保留编码、名称和完整路径快照；类别停用后只允许调减或删除历史预算。

## 3. 立项与审批

- 立项申请资源预算区展示预算总额、说明、分类明细、已分配和差额。
- 分类预算与项目、团队、WBS 概要和附件一同进入立项审批快照。
- 审批详情按类别表格展示金额、占比和依据，不展示 JSON。
- 驳回后编辑原草稿；批准后预算只读，项目启动时进入 V1 基线。

## 4. 项目预算

- 项目工作区新增“项目预算”页签。
- 展示当前预算总额、初始批准预算、累计变更金额、类别数量和分类明细。
- 本阶段不展示已使用、剩余预算和执行率。

## 5. 预算变更

- 新增 `PROJECT_BUDGET` 模块，预算头字段从 `PROJECT_INFO` 移出。
- 预算头支持是否需要预算、总额和说明；预算行支持新增、修改和删除。
- 一条分类预算行是一条最小变更项，审批详情按字段展示差异。
- 提交时模拟整张变更单的最终预算，校验分类合计与总额。
- 审批通过后由项目负责人确认应用，事务化写入并生成新基线。

## 6. 本阶段不做

- 工作包预算、预算占用、采购承诺、实际成本、工时成本、财务同步、多币种和税额拆分。
