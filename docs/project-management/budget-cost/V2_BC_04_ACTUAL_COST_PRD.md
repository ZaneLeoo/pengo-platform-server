# V2 预算与成本 04：实际成本登记与预算执行产品需求

## 1. 目标与边界

在已批准的项目分类预算和工作包预算之下，登记项目实际发生的成本，并回答“钱实际花了多少、还剩多少”。实际成本是事实记录，不改变计划预算，也不进入计划基线。

- 金额统一为人民币含税，保留两位小数。
- 实际成本可登记为“项目级”或“工作包级”；两者都必须挂接项目与有效末级成本类别。
- 实际成本不进入项目变更审批，通过项目状态、权限与审计保证可控。
- 本阶段不做：成本审批流、预算占用单据、采购承诺、工时成本、财务同步、多币种、税率和税额拆分。

## 2. 模型与术语

| 术语 | 定义 |
| --- | --- |
| 项目分类预算 | BC02 已批准的“项目 × 成本类别”预算总额，是实际成本的项目级上限。 |
| 工作包预算 | BC03 的“工作包 × 成本类别”预算分配行，是登记到该工作包成本的工作包级上限。 |
| 实际成本记录 | 一次实际发生的费用登记：项目 + 成本类别 +（可选）工作包 + 金额 + 发生日期 + 事由。 |
| 项目级成本 | 不归属工作包的实际成本，直接消耗项目分类预算。 |
| 工作包级成本 | 归属某个工作包的实际成本，同时受该工作包预算约束。 |
| 已发生成本 | 项目或工作包在某成本类别下的实际成本合计。 |
| 剩余预算 | 项目级：项目分类预算 - 该类别已发生成本；工作包级：工作包预算 - 该工作包该类别已发生成本。 |
| 执行率 | 已发生成本 / 对应预算上限。 |
| 待分配 | 沿用 BC03 口径：项目分类预算 - 工作包预算合计，不受实际成本影响。 |

## 3. 核心规则

### 3.1 登记约束

- 项目必须启用预算，且当前成本类别存在有效的项目分类预算，才可登记该类别实际成本。
- 实际成本必填：有效末级成本类别（自身及祖先均启用）、金额大于 0 且最多两位小数、发生日期、事由。
- 项目状态仅 `ACTIVE`、`PAUSED` 允许登记；`DRAFT`、`PENDING_APPROVAL`、`APPROVED`、`COMPLETED` 拒绝。
- 不指定工作包时记为项目级成本，直接按项目分类预算执行。
- 指定工作包时，工作包必须属于当前项目、节点类型为 `WORK_PACKAGE`、状态非 `COMPLETED`，且该工作包存在该成本类别的工作包预算；登记后该工作包该类别已发生成本不得超过该工作包预算。
- 项目级与工作包级合计后，该类别已发生成本不得超过项目分类预算；超出即拒绝登记或调增。
- 成本类别停用后禁止新增或调增；允许调减或删除历史成本记录（更正场景）。

### 3.2 更正与删除

- 项目负责人可更正或删除全部实际成本；登记人仅可更正或删除本人记录。管理员不作为业务越权特例。
- 更正只允许修改金额、发生日期、事由和工作包归属；不得修改项目与成本类别，避免预算口径漂移。
- 更正后必须重新满足全部预算上限约束。
- 删除或调减不做二次审批，但记录操作人、时间与变更前后值。

### 3.3 预算执行联动（补强既有规则）

- 工作包预算调减后不得低于该工作包该类别已发生成本；删除工作包预算前必须先删除该工作包该类别全部实际成本。
- 项目分类预算调减后不得低于该类别已发生成本；删除项目分类预算前该类别必须无实际成本。
- 项目取消预算（`budgetRequired = 0`）前必须无任何实际成本记录（含项目级与工作包级）。
- 成本类别引用保护覆盖实际成本表：存在实际成本后不允许删除、移动或新增下级。

### 3.4 权限与数据范围

- 查看沿用项目/工作包的数据范围：项目成员、项目负责人、申请人、审批人及既有可查看用户。
- 登记：项目成员；更正与删除：本人记录或项目负责人。
- 管理员不是业务越权特例；现阶段保留项目管理接口权限注解临时关闭，服务层校验不可绕过。

## 4. 页面与交互

### 4.1 项目预算页签

- 分类汇总表扩展列：项目分类预算、已分配、待分配、实际成本、剩余预算、执行率、状态。
- 新增“实际成本”明细区：按成本类别或工作包展开，展示发生日期、成本类别、工作包、金额、事由、登记人和最近更正。
- “登记实际成本”按钮弹窗：类别仅展示当前项目存在项目分类预算的有效末级类别；选择工作包时动态过滤没有对应类别预算或已完成的工作包。

### 4.2 工作包详情抽屉

- “预算”页签扩展：工作包预算、工作包实际成本、剩余、成本类别数量。
- 提供“登记工作包实际成本”入口，自动带入项目与工作包，仅展示该项目该工作包已有预算的类别。

### 4.3 无独立审批与版本

- 实际成本不进入 `PLAN_CHANGE`，不做版本比较分组；计划基线快照不包含实际成本，项目预算页签实时读取当前成本。

## 5. 本期不做

- 成本审批流、财务凭证；
- 预算占用单据、采购申请、合同、报销；
- 工时成本与物料成本自动归集；
- 财务同步、多币种、税率与税额拆分；
- 任务级、交付物级成本。
