# V2 预算与成本 01：成本类别产品需求

## 1. 目标

建立跨项目复用的成本分类口径，为后续项目预算、工作包预算和实际成本提供稳定的选择项。本阶段不维护预算金额，不登记成本，也不接入审批。

成本类别回答“钱花在哪一类”，成本来源回答“数据从哪里产生”。成本来源属于后续成本记录，本阶段不在成本类别中维护。

## 2. 角色与权限

- 具有成本类别菜单权限的配置人员可以查看和维护成本类别。
- 项目成员只能在后续预算、成本业务中选择有效的末级类别，本阶段不提供业务入口。
- 管理员不作为业务特例，所有操作均依据菜单权限和后端权限校验。

## 3. 类别结构

- 成本类别采用树形结构，最多三级。
- 类别编码由配置人员填写，全局唯一，只允许大写字母、数字和下划线，保存后不可修改。
- 同一上级下类别名称不可重复。
- 只有启用、祖先均启用且没有子级的类别可以作为业务选择项。
- 非末级类别仅用于汇总，不允许直接用于预算或成本。
- 已被业务引用的末级类别不得新增子级或移动父级。

## 4. 字段

| 字段 | 规则 |
| --- | --- |
| 类别编码 | 必填，全局唯一，保存后锁定 |
| 类别名称 | 必填，同级唯一 |
| 上级类别 | 根节点为空，最多三级 |
| 允许手工填报 | 仅末级类别用于后续成本登记 |
| 财务科目编码 | 可选，预留财务映射 |
| 财务科目名称 | 可选，预留财务映射 |
| 状态 | 启用、停用 |
| 类型 | 系统预置、自定义 |
| 排序 | 同级排序，默认 0 |
| 说明 | 可选，最多 500 字 |

## 5. 维护规则

- 系统预置类别不可删除、移动或修改编码；允许修改名称、手工填报标志、财务映射、说明、排序和状态。
- 自定义类别未被引用时可以移动；被引用后编码和父级锁定，只能修改展示信息或停用。
- 删除仅允许自定义、无子级且无业务引用的类别。
- 停用不删除历史；停用父级后整棵子树对新业务不可选，重新启用后按子节点自身状态恢复。
- 类别完整路径用于业务回显，例如“材料成本 / 样机材料”。

## 6. 预置类别

- 人工成本：内部人工、外部人工。
- 材料成本：样机材料、试生产材料。
- 外协成本：外协设计、外协加工、外协测试。
- 测试与认证、设备及工具、差旅、软件与技术服务、其他成本。

## 7. 页面

“项目管理 / 成本类别”使用树形表格：

- 顶部支持编码、名称和状态筛选，并提供新增根类别。
- 每行支持新增子级、编辑、启停和删除，按钮由后端能力字段与菜单权限共同控制。
- 表格展示编码、名称、完整路径、层级、末级、手工填报、财务映射、状态、类型和排序。
- 新增/编辑采用弹窗；选择上级时排除自身、后代和会超过三级的节点。

## 8. 本期不做

- 项目预算、工作包预算和实际成本。
- 成本来源、工时成本、物料成本和财务同步。
- 会计科目主数据、凭证、汇率和多币种。
