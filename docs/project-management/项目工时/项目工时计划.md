# V2 预算与成本阶段 5：项目工时、人工单价与内部人工成本

## Summary

参考 PLM 的“我的工时 + 任务关联工时 + 工时看板”模式，但补齐人工成本闭环：

`任务执行人按日填报 → 自然周提交审批 → 归档有效工时 → 按全局人员单价快照计价 → 形成内部人工实际成本 / 待处理成本`

首期以“真实投入与成本归集”为目标，不做工资、考勤、外部人员结算或加班倍率。

实施前新增独立文档目录，例如 `V2_BC_05_WORK_HOURS/`：

- `PRD.md`
- `TECH.md`
- `ACCEPTANCE.md`

## 核心业务设计

### 1. 菜单与入口

- 个人中心新增“我的工时”：个人唯一的工时台账、周工时单编辑、提交、撤回、更正。
- 项目管理新增：
  - “工时管理”：项目负责人、部门/成本管理员查看、筛选、审批结果追溯与待处理成本补计。
  - “人工单价”：仅财务/成本管理员维护全局人员小时单价。
- 任务详情增加“填报工时”快捷入口：预填当前任务，但最终仍进入“我的工时”完成保存。
- 项目和工作包页面只展示汇总，不提供项目级或工作包级直接填报入口。

### 2. 工时单与明细

- 一张工时单对应一个自然周（周一至周日），可包含多条日明细、多个项目和任务。
- 每条工时明细必须归属：
  - 填报人本人；
  - 一个当前有效项目；
  - 一个执行任务；
  - 任务所属工作包由系统自动带出。
- 仅任务执行人可为自己填报；项目负责人不代报，非执行人不可填报支援工时。
- 明细字段：
  - 填报日期、项目/任务/工作包快照；
  - 普通工时、加班标记；
  - 工时值（0.5 小时精度）；
  - 工作说明、成果说明；
  - 状态与审计信息。
- 每人每日普通工时累计最多 8 小时，含加班累计最多 12 小时；实现为可配置控制参数，首期使用上述默认值。
- 本周工时单可编辑；次周允许补报且必须填写补报原因；更早历史周不能直接新增，仅能走更正/补报申请。

### 3. 审批、更正与任务汇总

- 新增 `WORK_HOURS` 审批流程类型，复用现有审批流配置；周工时单提交时按已配置流程发起审批。
- 状态：草稿 → 审批中 → 已退回 / 已归档；草稿、退回可编辑，审批中可撤回。
- 任务 `actualHours` 改为只读汇总字段：仅统计已归档且未冲销的工时明细；不再手工维护。
- 已归档工时更正：
  - 用户从原记录发起“申请更正”，系统复制原明细形成关联的新更正明细；
  - 原记录及其有效人工成本标记为已冲销，不删除；
  - 更正明细进入新的周工时单并重新审批；
  - 审批归档后按新值重新参与工时和成本统计。

### 4. 全局人工单价与成本生成

- 人工单价全局维护，不按项目维护；菜单仅财务/成本管理员可见。
- 单价表按“人员 + 生效日期”维护，包含人员快照、有效起止日期、人民币小时单价、状态、维护审计。
- 同一人员的有效期不得重叠；单价变更不回写历史。
- 周工时审批归档时，按“填报日期”匹配有效单价，并把人员、单价、生效规则固化为工时成本快照。
- 普通与加班工时首期使用相同单价；加班标记仅用于统计和审批，预留后续倍率配置。
- 工时成本类别固定归属项目有效分类预算中的“内部人工”；实际成本仍按工作包与成本类别受预算控制。
- 成本处理状态：
  - `已归集`：单价有效、项目/工作包均有内部人工预算，自动生成不可手工修改的人工实际成本；
  - `待计价`：无有效人员单价；
  - `待归集`：存在单价但项目或工作包未配置内部人工预算；
  - `已冲销`：原工时被更正或被有效撤销后，对应成本失效。
- 成本管理员在“工时管理”筛选待计价/待归集记录，补齐单价或预算后，执行批量补计；补计前重新校验预算余额、工作包状态和单价有效性。
- 人工成本沿用现有实际成本表的预算控制，不允许因为工时自动归集而超出项目或工作包分类预算。

## 接口、数据与页面

- 新增工时周单、工时明细、人员单价、人工成本归集快照及更正关联数据结构；不复用采购实际成本来源字段。
- 工时周单接口支持：创建/查询、批量保存明细、提交、撤回、审批回调、发起更正、待处理成本查询与批量补计。
- 人工单价接口支持：分页查询、有效期校验的新建/修改/停用、按日期解析有效单价。
- 项目预算执行、工作包预算面板、项目预算页签增加：
  - 内部人工预算；
  - 已归集人工成本；
  - 待计价/待归集工时与预估待归集金额；
  - 不把待处理金额混入已发生实际成本。
- 工时管理提供按人员、项目、工作包、任务、周期间、审批状态、成本处理状态的 ProTable 查询；项目负责人只能看授权项目范围，成本管理员可看全量成本范围。
- 后续工时看板作为下一小阶段实现，基础数据预留项目、工作包、任务、人员、部门、日期、加班、成本状态等统计维度。

## 验收要点

- 执行人可从“我的工时”及任务快捷入口创建同一周多任务工时；非执行人无法填报。
- 0.5 小时精度、8/12 小时日累计限制、次周补报原因和更早历史限制正确。
- 草稿、提交、撤回、退回修改重提、审批归档完整可追溯。
- 已归档工时自动汇总到任务实际工时；审批中、退回、已冲销记录不计入。
- 有效单价和完整内部人工预算时，归档后生成正确的工作包级人工实际成本与单价快照。
- 缺单价形成待计价，缺预算形成待归集；成本管理员补齐条件后批量补计成功。
- 已归档记录更正后，原工时/成本冲销，新记录审批通过后重新生效。
- 单价有效期重叠、预算超额、已完成任务或工作包、无项目权限等场景均被拦截。
- 工时明细、审批详情、预算执行和处理记录均不展示原始 JSON。

## Assumptions

- 工时统一按小时记录，人民币内部结算单价，首期不做薪资、税费、考勤同步或外部人员结算。
- “内部人工”成本类别已存在；项目和工作包必须在预算阶段明确分配该类别，才可自动归集成本。
- 工时审批使用现有可配置工作流；管理员不作为业务权限特例。
- 项目专属单价、角色兜底单价、加班倍率、代报、工时看板和跨项目分摊不纳入本期。
