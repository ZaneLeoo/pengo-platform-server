# V2 预算与成本 05：项目工时、人工单价与内部人工成本

## 1. 目标与边界

本阶段建立项目人工投入和内部人工成本的可追溯闭环：任务执行人按日填报，按自然周提交审批；审批归档后工时计入任务实际工时，并按人员全局有效单价归集工作包级实际成本。

业务链路：任务执行人填报日工时（同步校验有效单价和可用预算）-> 周工时单审批 -> 已归档有效工时 -> 自动生成已归集人工成本。

本期只处理内部人工工时与成本归集；不处理薪资、考勤、税费、外部人员结算、跨项目分摊或财务凭证同步。

## 2. 术语与口径

| 术语 | 定义 |
| --- | --- |
| 自然周工时单 | 同一人员周一至周日的一张工时单，可有多条日明细、多个项目和任务。 |
| 工时明细 | 某人员在某日为某执行任务投入的工时，是事实与成本的最小粒度。 |
| 归档 | 周单审批通过后的有效状态。仅已归档且未冲销明细计入任务实际工时。 |
| 更正 | 保留历史的替换操作：旧明细及其成本被冲销，新明细重新审批。 |
| 人工单价 | 人员某有效期间内的人民币含税小时单价，由财务/成本管理员全局维护。 |
| 已归集 | 已按单价生成并记入预算执行的内部人工实际成本。 |

| 已冲销 | 原归档工时已被一条已归档的更正记录替换，原工时及原成本不再参与当前统计。 |

金额为人民币含税并保留两位小数；工时采用“直接填写时长”模式，以小时记录，最小单位为 0.5 小时（30 分钟）。允许 0.5、1、1.5、2 等值，不允许 0、负数或 0.3、2.25 等非半小时值。首期不填写起止时间范围，也不处理时段重叠、午休或跨日计算；加班与普通工时使用同一单价。

## 3. 角色、菜单和数据范围

| 角色 | 主要能力 |
| --- | --- |
| 任务执行人 | 在我的工时填报本人执行任务，保存、提交、撤回和申请更正。 |
| 项目负责人 | 查看有权限项目的工时汇总和明细，不代报、不维护单价。 |
| 审批人 | 按 WORK_HOURS 流程审批周工时单。 |
| 成本管理员 | 在工时管理查看其成本数据范围内的工时及内部人工成本。 |
| 财务/成本管理员 | 维护全局人员小时单价。 |

- 个人中心新增“我的工时”，是个人唯一的工时编辑与台账入口。
- 项目管理新增“工时管理”和“人工单价”。
- 任务详情提供“填报工时”快捷入口，预选任务后进入我的工时；项目和工作包页仅显示汇总，不提供直接填报。
- 管理员不是业务越权特例；服务层按任务执行人、项目数据范围、负责人和成本范围校验。

## 4. 周工时单和明细规则

### 4.1 周期与状态

- 每人每自然周仅一张周单，周一至周日为固定周期。
- 当前周可新增、编辑；紧邻上一周可补报但必须填写补报原因；更早历史周不能直接新增。
- 草稿和退回周单可编辑；审批中仅可撤回；归档后不可直接编辑。

状态机：草稿(DRAFT) -> 审批中(IN_APPROVAL) -> 已归档(ARCHIVED)；审批中可退回(RETURNED)，也可由发起人撤回至草稿。

提交按周单走一次 WORK_HOURS 审批，不按明细逐条审批。无可用流程或无法解析审批人时不得提交，草稿保留。

### 4.2 明细字段和选择范围

每条明细必须填写：日期、项目、执行任务、工时、工作说明、成果/结果说明；加班标记可选。系统从任务自动带出并快照项目、工作包、任务与人员信息。

- 仅能选择填报人本人当前被指派为执行人的任务。
- 项目必须为执行中或暂停中；不支持项目级、工作包级、未指派或他人任务填报。
- 工作包由任务推导，用户不能手动改动。
- 工时大于 0 且必须为 0.5 的整数倍。
- 按填报人和日期汇总：普通工时最多 8 小时，含加班总工时最多 12 小时。首期使用默认值，后续应参数化。
- 保存草稿时即校验工时日期存在填报人的有效小时单价、项目和所属工作包均启用“内部人工”预算且本次工时金额不超过当前可用余额；不满足时不得保存或提交，并明确提示缺失单价、未配置预算或预算不足。
- 同一周单内不得重复填报同一日期、同一任务；如确有不同事项，合并为一条明细填写说明。本期不支持同任务同日拆分多条。

前端在录入时实时校验，后端草稿保存时执行同一套完整校验；提交和归档仅保留状态、数据未被篡改及并发场景下预算余额的最终一致性保护。审批归档后，任务 actualHours 由全部已归档、未冲销明细自动聚合，不再允许手工维护。

## 5. 更正与冲销

对已归档明细申请更正时，系统复制原记录生成带原记录关联的新明细，用户填写更正原因并按正常周单重新审批；新明细保存时同样校验单价和预算。新明细归档后，原明细标记已冲销；原明细对应人工实际成本也被冲销，并按新明细的单价快照生成新的人工成本。

冲销不删除历史，但旧工时和成本不再参与任务实际工时、已发生成本和预算执行。一个原记录存在审批中或已归档的替换记录时，不允许再次发起更正。

## 6. 全局人工单价

- 单价按人员全局维护，不按项目、部门、角色或工作包分别维护。
- 单价行包含人员及快照、有效开始/结束日期、人民币小时单价、状态和维护审计。
- 同一人员的有效期间不得重叠；归档时按工时日期匹配，并快照单价和有效期。后续改价不得回算历史。
- 加班首期不加倍率，仅保留统计和审批标记。
- 人员单价仅财务/成本管理员可维护；项目负责人只能看本项目人工成本汇总，不看个人单价明细。

## 7. 成本归集与预算控制

内部人工使用已有成本类别 INTERNAL_LABOR / 内部人工。每个工时均由任务归属工作包，因此人工成本始终是工作包级成本，并同时受项目分类预算、工作包分类预算和实际成本上限控制。

保存工时时必须已具备有效单价、项目内部人工分类预算、工作包内部人工预算及足够余额。审批归档后自动生成不可手工修改的工作包级内部人工实际成本，状态为“已归集”；原记录被更正替换后，原工时及原成本状态为“已冲销”。

本期不设置待计价、待归集或成本管理员批量补计。单价或预算配置缺失时，由填报人联系相应维护人补齐后再填报；预算余额不足时，须先走既有预算变更流程。归档事务仍会锁定并复核余额，防止并发提交造成超预算；若校验失败，不生成成本且该周单不得完成归档，按流程异常返回待处理。

## 8. 页面要求

### 8.1 我的工时

按自然周切换，显示周单状态、补报提示、普通/加班/总工时和提交撤回操作；日明细采用直接填写时长，支持增删改和实时日累计、单价、预算校验。已归档明细展示归集金额，并仅提供申请更正入口。

### 8.2 工时管理与人工单价

工时管理使用 ProTable，支持人员、部门、项目、工作包、任务、周期间、审批状态、成本状态和加班筛选。人工单价使用 ProTable，支持人员、状态和有效日期筛选，并校验金额、日期与有效期重叠。

项目预算、工作包预算、预算执行展示内部人工预算、已归集人工成本和剩余预算。

## 9. 本期不做

- 薪资、考勤、请假、打卡、税费、社保和外部人员结算；
- 项目专属单价、角色兜底单价、加班倍率；
- 代报、跨项目或跨任务分摊；
- 独立工时看板、绩效和工资核算。
