# 项目工时文档产出计划

在项目管理 V2 文档目录下新增“项目工时”文件夹，并创建两份独立文档：

- `项目工时/PRD.md`：完整业务需求
  - 我的工时、任务快捷填报、自然周工时单、补报、更正与审批流程
  - 人员全局单价、待计价/待归集、内部人工实际成本与预算控制
  - 权限、菜单、状态机、页面与字段设计、范围边界
- `项目工时/TECH.md`：技术方案
  - 数据表、状态与关联关系
  - 后端接口、审批回调、成本归集与冲销逻辑
  - 前端菜单、页面、任务快捷入口与预算汇总改造
  - 数据校验、迁移、测试策略与实施顺序

文档会以本轮已确认的规则为唯一依据：自然周提交、配置 `WORK_HOURS` 审批流、仅任务执行人自报、全局人员有效期单价、缺单价/预算不阻塞归档但进入待处理、成本管理员批量补计、加班同单价、归档工时自动汇总任务实际工时。
