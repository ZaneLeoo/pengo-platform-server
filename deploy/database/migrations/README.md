# 部署增量 SQL

此目录只存放“当前数据库基线 55”之后需要在服务器自动执行的增量脚本。

## 命名规则

```text
V0056__add_example_table.sql
V0057__adjust_example_permission.sql
```

- `V` 后必须是递增数字版本。
- 使用两个下划线分隔版本和说明。
- 已经发布的脚本禁止修改；修改会导致部署时校验和不一致并终止。
- 每个脚本只执行一次，成功后登记到 `pm_schema_history`。
- 新脚本应尽量可重复执行；MySQL DDL 不能完整事务回滚，发布前必须在数据库副本演练。
- 不要在这里放测试账号、演示项目或清库脚本。

当前的 `01-55` 历史脚本不从这里自动重放。首次部署应导入已经验收的 `pm` 完整备份，或在构建发布包时通过 `-BaselineSqlPath` 携带基线文件。
